description: Lanjutkan kerja efn-lead dari status sesi terakhir
---

Baca hanya bagian `## Status sesi` di `docs/agent-reports/efn-lead.md`, lalu `git status` + `git log --oneline -5` untuk memastikan branch dan commit cocok dengan catatan. Belum membuka file lain.

Jawab maksimal 5 baris: posisi terakhir, langkah berikutnya yang akan diambil, dan blocker yang butuh jawaban user.
Bila catatan tidak cocok dengan kondisi git (branch beda, commit hilang), laporkan selisihnya dan tanyakan dulu.
Bila tidak ada blocker, langsung kerjakan langkah berikutnya.
